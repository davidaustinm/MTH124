    Handout Section 3.1: Exponential Functions \(f(t)=ab^t\)
    

    MTH 124
    🔗

    Definition 82. Definition 3.1.2.

    Let \(b\) be a real number such that \(b>0\) and \(b\ne 1\text{.}\) We call the function defined by
    \begin{equation*} f(t) = b^t \end{equation*}
    an exponential function with base \(b\text{.}\) ** So \(f(t) = ab^t\) is a vertical stretch of \(b^t\text{.}\) **
    🔗
    🔗
    Important! \(b^0 = \) for ANY \(b\ne 0\text{.}\) We call \(b\) the growth factor. If \({b=1+r}\text{,}\) we call \(r\) the growth rate.
    🔗
    If \(b\gt 1\text{,}\) we call \({f(t) = b^t}\) “exponential growth.”
    🔗
    If \(0\lt b \lt 1\) we call it “exponential decay.”
    🔗

    Activity 83. Activity 3.1.2.

    In Desmos, define the function \(g(t) = ab^t\) and create sliders for both \(a\) and \(b\) when prompted. Click on the sliders to set the minimum value for each to \(0.1\) and the maximum value to \(10\text{.}\) Note that for \(g(t)\) to be an exponential function, we require \(b\ne 1\text{,}\) even though the slider for \(b\) will allow this value.
    🔗

    (a)

    What is the domain of \(g(t) = ab^t\text{?}\)
    🔗
    Solution.
    All real numbers, or \((-\infty, \infty)\)
    🔗
    🔗
    🔗

    (b)

    What is the range of \(g(t)=ab^t\text{?}\)
    🔗
    Solution.
    All positive real numbers, or \((0,\infty)\)
    🔗
    🔗
    🔗

    (c)

    What is the \(y\)-intercept of \(g(t)=ab^t\text{?}\)
    🔗
    Solution.
    \(g(0) = a\) so the y-intercept is \((0,a)\)
    🔗
    🔗
    🔗

    (d)

    How does changing the value of \(b\) affect the shape and behavior of the graph of \(g(t)=ab^t\text{?}\) Write several sentences to explain.
    🔗
    Solution.
    A lot you could say here. If \(0\lt b \lt 1\) the graph is decreasing and approaches \(0\) eventually. If \(b \gt 1\) then the graph is always growing and goes to infinity.
    🔗
    🔗
    🔗

    (e)

    For what values of the growth factor \(b\) is the corresponding growth rate positive? For which \(b\)-values is the growth rate negative?
    🔗
    Solution.
    If the growth factor \(b\gt 1\text{,}\) then \(b=1+r \gt 1\) so \(r \gt 0\text{,}\) or in other words the growth rate is positive. Growth! If \(0\lt b\lt 1\) then \(b=1+r \lt 1\) so the growth rate \(r \lt 0\text{.}\) Decay!
    🔗
    🔗
    🔗

    (f)

    Consider the graphs of the exponential functions \(p\) (solid) and \(q\) (dashed) provided in the figure below. If \(p(t)=ab^t\) and \(q(t)=cd^t\text{,}\) what can you say about the values \(a, b, c,\) and \(d\) (beyond the fact that all are positive and \(b\ne 1\) and \(d\ne 1\) )? For instance, can you say a certain value is larger than another? Or that one of the values is less than 1?
    🔗
    Solution.
    Since \(a, c\) are the y-intercepts, we can see that \(a \gt c\) because it’s higher up on the y-axis. But since \(p\) shows exponential decay than \(0\lt b \lt 1\text{,}\) but \(q\) is exponential growth then \(d\gt 1\text{.}\)
    🔗
    🔗
    🔗
    🔗
    All you need to find the formula of an exponential function is two points! And algebra...
    🔗

    Activity 84. Activity 3.1.3. Finding Formulas.

    The value of an automobile is depreciating. When the car is 3 years old, its value is $\(12500\text{;}\) when the car is 7 years old, its value is $\(6500\text{.}\)
    🔗

    (a)

    Suppose the car’s value \(t\) years after its purchase is given by the function \(V(t)\) and that \(V\) is exponential with form \(V(t) = ab^t\text{,}\) what are the values of \(a\) and \(b\text{?}\) Find \(a\) and \(b\) both exactly and approximately.
    🔗
    Solution.
    Point 1: \((3,12500)\) or plugging in \(12500 = ab^3\text{.}\)
    🔗
    Point 2: \((7,6500)\) or in other words \(6500 = ab^7\text{.}\)
    🔗
    Then we can take the ratio between them:
    \begin{equation*} \frac{6500}{12500} = \frac{ab^7}{ab^3} \end{equation*}
    which simplifies to
    \begin{equation*} \frac{13}{25} = b^4. \end{equation*}
    Or in other words, taking the 4th root of each side, we have \({b = (\frac{13}{25})^{1/4}}\text{.}\)
    🔗
    Now to find \(a\text{,}\) we can plug \(b\) back into either equation we know. For zero reason whatsoever I’ll choose \(12500 = ab^3\text{,}\) which will then become
    \begin{equation*} 12500 = a \left((\frac{13}{25})^{1/4}\right)^3 = a \left(\frac{13}{25}\right)^{3/4} \end{equation*}
    and since \(a\) is multiplied by stuff we can just divide and get
    \begin{equation*} \frac{12500}{(\frac{13}{25})^{3/4}} = a. \end{equation*}
    Yes they are terrible, but they are exact. The entire formula would be
    \begin{equation*} V(t) = \frac{12500}{(\frac{13}{25})^{3/4}} \left(\left(\frac{13}{25}\right)^{3/4}\right)^t. \end{equation*}
    If we approximate, \(a\approx 20413\) and \(b\approx 0.8492\text{,}\) so \({V(t)\approx 20413(0.8492)^t}\text{.}\)
    🔗
    🔗
    🔗

    (b)

    Using the exponential model determined in (a), determine the purchase value of the car and then use Desmos to estimate when the car will be worth less than $\(1000\text{.}\)
    🔗
    Solution.
    The purchase price is at \(t=0\text{,}\) and we have \(V(0) = a \approx 20413\text{.}\)
    🔗
    If the worth is $1000, then \(V(t) = 1000\text{.}\) Plot \(V(t)\) and \(y=1000\) in Desmos and see where they intersect. This happens at \(t=18.45\text{,}\) so after about 18.5 years the car is worth less than $1000.
    🔗
    🔗
    🔗

    (c)

    Suppose instead that the car’s value is modeled by a linear function \(L\) and satisfies the values stated at the outset of this activity. Find a formula for \(L(t)\) and determine both the purchase value of the car and when the car will be worth $\(1000\text{.}\)
    🔗
    Solution.
    Lines! Need the slope between our two points \((3,125000), (7, 6500)\text{.}\) Slope is
    \begin{equation*} m = \frac{6500-12500}{7-3} = -1500. \end{equation*}
    Pick a point and do point-slope form:
    \begin{equation*} L(t) = -1500 (t-3) + 12500. \end{equation*}
    If \(L(t) = 1000\text{,}\) this is true when \(t=10.67\text{,}\) so for a linear function it would only take a little over 10.5 years before the car is worth less than $1000.
    🔗
    🔗
    🔗

    (d)

    Which model do you think is more realistic? Why?
    🔗
    Solution.
    Car values don’t usually decrease linearly, so probably exponential.
    🔗
    🔗
    🔗
    🔗
    Notice below we have two exponential functions. On the left we have exponential growth (\(b \gt 1\)), and on the right we have exponential decay (\(0 \lt b \lt 1\)). The exponential growth model corresponds to an increasing function, while exponential decay corresponds to a decreasing function.
    🔗
    BUT EACH bends upwards always, and therefore each is concave up.
    🔗

    Trends in exponential function behavior.

    For an exponential function of the form \(f(t) = ab^t\) where \(a\) and \(b\) are both positive with \(b\ne 1\text{,}\)
    🔗
    • if \(b>1\text{,}\) then \(f\) is always increasing and always increases at an increasing rate (increasing and concave up);
      🔗
      🔗
    • if \(0<b<1\text{,}\) then \(f\) is always decreasing and always decreases at an increasing rate (decreasing and concave up).
      🔗
      🔗
    🔗
    🔗

    Activity 85. Activity 3.1.4.

    For each of the following prompts, give an example of a function that satisfies the stated characteristics by both providing a formula and sketching a graph. (They don’t all have to be exponential functions!)
    🔗

    (a)

    A function \(p\) that is always decreasing and decreases at a constant rate.
    🔗
    Solution.
    Something that changes at a constant rate is a line! And it just needs a negative slope. \(p(x)=-x\) is one example, there are many.
    🔗
    🔗
    🔗

    (b)

    A function \(q\) that is always increasing and increases at an increasing rate.
    🔗
    Solution.
    This sounds like exponential growth! Something like \(q(x)=2^x\) is always increasing (growth) and always concave up (or increasing at an increasing rate)! There are many examples that will work.
    🔗
    🔗
    🔗

    (c)

    A function \(r\) that is always increasing for \(t<2\text{,}\) always decreasing for \(t>2\text{,}\) and is always changing at a decreasing rate.
    🔗
    Solution.
    Always concave down (frowny face) bue first increasing then decreasing. Draw a picture.... this seems like a parabola will do, as long as it’s vertex is at \(x=2\) and it’s point downward. Well, \(r(x)=-(x-2)^2\) will do that. (Also many possibilities)
    🔗
    🔗
    🔗

    (d)

    A function \(s\) that is always increasing and increases at a decreasing rate. (Hint: to find a formula, think about how you might use a transformation of a familiar function.)
    🔗
    Solution.
    Increase at a decreasing rate, that’s concave down. We have done to much with that. But exponential functions are always concave up, so if we flip them they become concave down. So if we take an exponential decay which is always decreasing and concave up, and we flip it over the x-axis, then it’s increasing and concave down. So \(s(x)=-(\frac12)^x\) should work.
    🔗
    🔗
    🔗

    (e)

    A function \(u\) that is always decreasing and decreases at a decreasing rate.
    🔗
    Solution.
    Again concave down, so we’ll use the same logic as the previous part and flip an exponential function. If we choose exponential growth which is increasing and concave up, then flipping it would make it decreasing and concave down. So for example \(u(x)=-2^x\) will work.
    🔗
    🔗
    🔗
    🔗
