    Activity 103. Trig Practice.

    Each of the graphs below shows a function of the form \({y = a\sin(k(t-b)) + c}\text{.}\) All graphs use the same scales so you can compare them directly.
    🔗

    (a)

    Which graph has the greatest amplitude? Which has the smallest amplitude?
    🔗
    Solution.
    The amplitude is half the distance from the minimum to the maximum. Graph D runs from \(-4\) to \(4\text{,}\) so its amplitude is 4. This is the largest amplitude. Graph C runs from \(1\) to \(3\text{,}\) so its amplitude is 1, which is the smallest amplitude.
    🔗
    🔗
    🔗

    (b)

    Which graph(s) have an amplitude of 3?
    🔗
    Solution.
    Graph A and F.
    🔗
    🔗
    🔗

    (c)

    Which graph(s) have the longest period? Which graph(s) have the shortest period?
    🔗
    Solution.
    Longest: D (period 8). Shortest: B and F (period 2). The period is the horizontal length of one full cycle. Graph D completes exactly one cycle on \([0,8]\text{,}\) so its period is 8. Graphs B and F complete four cycles on \([0,8]\text{,}\) so their period is 2.
    🔗
    🔗
    🔗

    (d)

    Which graph(s) have a period of 4?
    🔗
    Solution.
    Graphs A and E.
    🔗
    🔗
    🔗

    (e)

    Which graph(s) have the midline \(y = 0\text{?}\) Which graph(s) have the highest midline? Which have the lowest midline?
    🔗
    Solution.
    The midline is halfway between the maximum and minimum. The midlines are: A, \(y=1\text{;}\) B, \(y=-1\text{;}\) C, \(y=2\text{;}\) D, \(y=0\text{;}\) E, \(y=3\text{;}\) F, \(y=-2\text{.}\) So Graph D has the highest midline, and graph F has the lowest.
    🔗
    🔗
    🔗

    (f)

    Find two pairs of graphs that have the same amplitude but different periods.
    🔗
    Solution.
    B and E (amplitude 2, periods 2 and 4); A and F (amplitude 3, periods 4 and 2).
    🔗
    🔗
    🔗

    (g)

    Which graph(s) are concave up on the interval \((4,8)\text{?}\) Which graph(s) are increasing on \((2,4)\text{?}\)
    🔗
    Solution.
    A sine function (and cosine function) is concave up exactly where it lies below its midline (it’s bending upward!). Graph D is concave up on the whole interval from \((4,8)\text{.}\) Others such as A and C are only concave up on part of that interval.
    🔗
    On \((2,4)\text{,}\) Graph E goes from its lowest point (minimum) at \(t=2\) up to its highest point (maximum) at \(t=4\text{,}\) so it is increasing the whole time. Others are not increasing over that whole interval.
    🔗
    🔗
    🔗

    (h)

    Choose 1+ of the graphs and write a possible formula of the form \({y = a\sin(k(t-b)) + c}\text{.}\)
    🔗
    Solution.
    The amplitude is almost \(a\text{,}\) though \(a\) could be positive or negative depending on if it looks like sine or flipped sine. The midline tells us the value of \(c\text{.}\) The value of \(k\) is \(\frac{2\pi}{Period}\text{.}\) Finally the value of \(b\) comes from a horizontal shift to find the anchor point. All of these could be rewritten with different values of \(b\) (and a possible sign change of the value of \(a\)), but here are the “simplest” formulas (i.e. the first positive anchor point is the most common choice from my experience).
    🔗
    • A: \(y = 3\sin\left(\frac{\pi}{2}(t-1)\right) + 1\)
      🔗
      🔗
    • B: \(y = 2\sin\left(\pi(t-0.5)\right) - 1\)
      🔗
      🔗
    • C: \(y = \sin\left(\frac{\pi}{3}(t-2)\right)+2\)
      🔗
      🔗
    • D: \(y = 4\sin\left(\frac{\pi}{4}t\right)\)
      🔗
      🔗
    • E: \(y = -2\sin\left(\frac{\pi}{2}(t-1)\right) + 3\)
      🔗
      🔗
    • F: \(y = -3\sin\left(\pi t\right) - 2\)
      🔗
      🔗
    🔗

    Activity 104.

    Practice finding exponential functions.
    🔗

    (a)

    Find the equation for the exponential function of the form \({p(t) = ab^t}\) that goes through the points: \({(4,10)}\) and \({(8,2)}\)
    🔗
    Solution.
    Divide the two equations: \(\dfrac{ab^8}{ab^4} = \dfrac{2}{10}\text{,}\) so \(b^4 = \dfrac{1}{5}\) and \(b = \left(\dfrac{1}{5}\right)^{1/4}\text{.}\) Then \(ab^4 = 10\) gives \(a\cdot\dfrac{1}{5} = 10\text{,}\) so \(a = 50\text{.}\) So \({p(t) = 50\left(\frac{1}{5}\right)^{t/4}}\)
    🔗
    🔗
    🔗

    (b)

    Find the equation for the exponential function of the form \({p(t) = ab^t}\) that goes through the points: \({(4.4,1.2)}\) and \({(10.4,9)}\)
    🔗
    Solution.
    Divide the two equations: \(\dfrac{ab^{10.4}}{ab^{4.4}} = \dfrac{9}{1.2}\text{,}\) so \(b^6 = 7.5\) and \(b = 7.5^{1/6}\approx 1.399\text{.}\) Then \(ab^{4.4} = 1.2\) gives \(a = \dfrac{1.2}{7.5^{4.4/6}} \approx 0.274\text{.}\) So \({p(t)= \dfrac{1.2}{7.5^{4.4/6}} (7.5^{1/6})^t\approx 0.274(1.399)^t}\text{.}\)
    🔗
    🔗
    🔗

    Activity 106.

    A bacteria population grows according to \(P(t) = 1000 \cdot 10^{0.5t}\text{,}\) where \(t\) is time in hours.
    🔗

    (a)

    Find the initial population.
    🔗
    Solution.
    \(P(0) = 1000\cdot 10^0 = 1000\text{.}\)
    🔗
    🔗
    🔗

    (b)

    Find the population after 2 hours.
    🔗
    Solution.
    \(P(2) = 1000\cdot 10^{0.5\cdot 2} = 1000\cdot 10 = 10,000\text{.}\)
    🔗
    🔗
    🔗

    (c)

    Find the exact time when the population is 3000. (There should be a log in your answer.)
    🔗
    Solution.
    Solve \(1000\cdot 10^{0.5t} = 3000\text{.}\) Dividing by 1000 gives \(10^{0.5t} = 3\text{.}\) Then \(0.5t = \log 3\text{,}\) so \(t = 2\log 3\) hours (this is approximately \(0.954\) hours).
    🔗
    🔗
    🔗
    🔗

    Activity 107.

    A radioactive substance in grams decays according to \(A(t) = 500 \cdot 10^{kt}\text{,}\) where \(t\) is time in years and \(k\) is some unknown number.
    🔗

    (a)

    If after 5 years there was 250 grams of the substance, what is \(k\text{?}\)
    🔗
    Solution.
    Plug in \(t=5\) and the output \(250\text{.}\) Solve \(250 = 500\cdot 10^{5k}\text{.}\) Then \(\frac{1}{2} = 10^{5k}\text{,}\) so \(5k = \log\left(\dfrac{1}{2}\right) \) and \(k = \dfrac15\log(\frac12)\) (which is approximately \(-0.0602\)).
    🔗
    🔗
    🔗

    Activity 108.

    An investment grows according to \(A(t) = 5000 \cdot 10^{0.04t}\text{,}\) where \(t\) is time in years.
    🔗

    (a)

    When will the investment double?
    🔗
    Solution.
    Doubling means \(A(t) = 10,000\text{.}\) So we are solving \(10000 = 5000\cdot 10^{0.04t}\text{,}\) which simplifies to get \(2 = 10^{0.04t}\text{.}\) Then \(\log(2) = 0.04t\text{,}\) so \(t = \frac{1}{0.04}\log(2) = 25\log(2)\) years. (This is approximately \(7.53\text{.}\))
    🔗
    🔗
    🔗

    Activity 109.

    The intensity of an earthquake is measured as \(I(M) = I_0 \cdot 10^M\text{,}\) where \(M\) is the magnitude and \(I_0\) is some unknown initial intensity.
    🔗

    (a)

    Write the intensity of a magnitude 6 earthquake and of a magnitude 4 earthquake in terms of \(I_0\text{.}\)
    🔗
    Solution.
    Substitute \(M=6\) and \(M=4\) into \(I(M) = I_0\cdot 10^M\text{.}\) Thus we get: \(I(6) = I_0\cdot 10^6\) and \(I(4) = I_0\cdot 10^4\text{.}\)
    🔗
    🔗
    🔗

    (b)

    How many times more intense is a magnitude 6 earthquake than a magnitude 4 earthquake?
    🔗
    Solution.
    \(\dfrac{I(6)}{I(4)} = \dfrac{I_0\cdot 10^6}{I_0\cdot 10^4} = 10^2 = 100\text{.}\) So 100 times bigger.
    🔗
    🔗

    Activity 111.

    A cooling object follows \(T(t) = 20 + 80 \cdot e^{-0.23t}\text{,}\) where \(T\) is temperature in Celsius and \(t\) is time in minutes.
    🔗

    (a)

    What is the initial temperature of the object?
    🔗
    Solution.
    \(T(0) = 20 + 80e^0 = 100\) degrees.
    🔗
    🔗
    🔗

    (b)

    What is the temperature after 10 minutes?
    🔗
    Solution.
    \(T(10) = 20 + 80e^{-0.23\cdot 10} = 20 + 80e^{-2.3}\) degrees. This is actually the exact answer. It turns out to be approximately \(T(10)\approx 28.02\) degrees.
    🔗
    🔗
    🔗

    (c)

    What will the temperature approach in the long term?
    🔗
    Solution.
    As \(t\to\infty\text{,}\) \(e^{-0.23t}\to 0\text{,}\) so \(T(t)\to 20 + 0 = 20\text{.}\) That is, in the long term it will tend towards the horizontal asymptote of \(y=20\) degrees.
    🔗
    🔗
    🔗
    🔗

    Activity 112.

    The population of a city grows according to \(P(t) = 10000e^{0.03t}\text{,}\) where \(t\) is time in years.
    🔗

    (a)

    Find the initial population of the city.
    🔗
    Solution.
    \(P(0) = 10000e^0 = 10,000\text{.}\)
    🔗
    🔗
    🔗

    (b)

    What is the population after 10 years?
    🔗
    Solution.
    \(P(10) = 10000e^{0.03\cdot 10} = 10000e^{0.3}\text{.}\) We would stop here for an exact answer, but this is approximately \(13,499\text{.}\)
    🔗
    🔗
    🔗

    (c)

    How long until the population reaches 30,000?
    🔗
    Solution.
    We are looking for \(t\) when \(P(t) = 30000\text{,}\) so we solve \(30000 = 10000e^{0.03t}\) for \(t\text{.}\) Then this simplifies to \(3 = e^{0.03t}\text{,}\) so \(0.03t = \ln(3)\) and \(t = \dfrac{1}{0.03}\ln(3)\) years (exactly). This is approximately \(36.6\) years.
    🔗
    🔗
    🔗

    Activity 113.

    A radioactive element decays according to \(N(t) = N_0 e^{kt}\text{,}\) where \(t\) is time in days and \(N_0, k\) are unknown.
    🔗

    (a)

    If there is initially 200 grams, find one of the unknowns.
    🔗
    Solution.
    We know \(N(0)=200\) from the data point, but from the model we have \(N(0) = N_0e^0 = N_0\text{,}\) so the initial amount is \(N_0 = 200\text{.}\)
    🔗
    🔗
    🔗

    (b)

    If after 7 days there is 150 grams, find the other unknown.
    🔗
    Solution.

    Activity 114.

    Compound interest is calculated as \(A(t) = 1000e^{0.05t}\) where \(t\) is time in years.
    🔗

    (a)

    What is the initial amount you invest?
    🔗
    Solution.
    \(A(0) = 1000e^0 = 1000\text{.}\) ($1000)
    🔗
    🔗
    🔗

    (b)

    How long until the initial amount doubles?
    🔗
    Solution.
    If it doubles we’ll have 2000, so \(A(t) = 2000\text{.}\) So we solve \(2000 = 1000e^{0.05t}\text{,}\) which simplifies to \(2 = e^{0.05t}\text{.}\) Then \(0.05t = \ln(2)\text{,}\) so \(t = \frac{1}{0.05}\ln(2)= 20\ln(2)\) years. (Exact). This is approximately \(13.9\) years!
