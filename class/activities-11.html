    Handout Section 1.7: Inverse Functions
    

    Definition 41. Definition 1.7.1.

    Let \(f:A\rightarrow B\) be a function. If there exists a function \(g:B\rightarrow A\) such that
    \begin{equation*} g(f(a)) = a, \ \ \ \text{ and } \ \ \ f(g(b))=b \end{equation*}
    for each \(a\) in \(A\) and each \(b\) in \(B\text{,}\) then we say that \(f\) has an inverse function and that the function \(g\) is the inverse of \(f\text{.}\) (In other words, they undo each other!)
    🔗
    🔗
    Big picture: if \(y=f(x)\) is a function with an inverse, \(f(x)\) inputs \(x\) and outputs \(y\text{.}\) So the inverse of \(f\) would input and output .
    🔗
    Notation: We write the inverse of \(f\) as \(f^{-1}\text{,}\) and we read it as \(f-\)inverse. Essentially, the inverse of a function “undoes” the original function, so you get back to where you started.
    🔗

    Activity 42. Activity 1.7.2.

    Recall Dolbear’s function \(F = D(N) = 40 + \frac14N\) that converts the number, \(N\text{,}\) of snowy tree cricket chirps per minute to a corresponding Fahrenheit temperature. We have earlier established that the domain of \(D\) is \([40,180]\) and the range of \(D\) is \([50,85]\text{.}\)
    🔗

    (a)

    Solve the equation \(F = 40+\frac14N\) for \(N\) in terms of \(F\text{.}\) (That is we should get \(N=\) stuff in terms of \(F\text{.}\)) Call the resulting function \(N=E(F)\text{.}\)
    🔗
    🔗

    (b)

    Explain in words the process or effect of the function \(N=E(F)\text{.}\) What does it take as input? What does it generate as output?
    🔗
    🔗

    (c)

    Use the function \(E\) that you found in (a.) to compute \(E(D(N))\text{.}\) Simplify your result as much as possible. Do likewise for \(D(E(F))\text{.}\) What do you notice about these two composite functions?
    🔗
    🔗

    (d)

    Consider the equations \(F = 40+\frac14N\) and \(N=4(F-40)\text{.}\) Do these equations express different relationships between \(F\) and \(N\text{,}\) or do they express the same relationship in two different ways? Explain.
    🔗
    🔗
    🔗

    Two perspectives from a function and its inverse function.

    If \(y=f(t)\) has an inverse function, then the equations
    \begin{equation*} y=f(t) \text{ and } t=f^{-1}(y) \end{equation*}
    say the exact same thing but from two different perspectives.
    🔗
    🔗

    Horizontal Line Test.

    A function whose graph lies in the \(x\)-\(y\) plane has a corresponding inverse function if and only if every horizontal line intersects the graph at most once. When the graph passes this test, the horizontal coordinate of each point on the graph can be viewed as a function of the vertical coordinate of the point.
    🔗
    🔗
    Think about it in terms of inputs and outputs. An inverse function flips the input and the output, so what was formerly on the \(y-\)axis is now the input, and what was formerly on the \(x-\)axis is now the output.
    🔗

    🔗

    Properties of an inverse function.

    Let \(f\) be a function with an inverse function, \(f^{-1}\text{.}\) Then:
    🔗
    • if \(f\) has domain \(A\) and range \(B\text{,}\) then \(f^{-1}\) has domain \(B\) and range \(A\) (domain and range swap!)
      🔗
      🔗
    • The functions \(f\) and \(f^{-1}\) reverse one anothers’ processes. Symbolically, \(f^{-1}(f(a))=a\) for every input \(a\) in the domain of \(f\text{,}\) and similarly, \(f(f^{-1}(b))=b\) for every input \(b\) in the domain of \(f^{-1}\text{.}\)
      🔗
      🔗
    • Both \(f\) and \(f^{-1}\) express the exact same relationship from a different perspective.
      🔗
      🔗
    • If \(y=f(x)\text{,}\) then the points \((x,y)\) lies on the graph of \(f\text{.}\) Then \(x=f^{-1}(y)\text{,}\) and the point \((y,x)\) lies on the graph of \(f^{-1}\text{.}\)
      🔗
      🔗
    🔗
    🔗
    The last point for example says that if \((0,1)\) is a point on the graph of \(f\text{,}\) then \((1,0)\) is a point on the graph of \(f^{-1}\text{,}\) because the input and output switch!
    🔗
    Graphically, an inverse function is a reflection across the line \(y=x\text{.}\) See the picture of \(f\) (the top curve) and \(f^{-1}\) (the bottom curve) below, and the line \(y=x\) between them. (Graph is not for the next activity.)

    Activity 44. Activity 1.7.4.

    During a major rainstorm, the rainfall at Gerald R. Ford Airport is measured on a frequent basis for a 10-hour period of time. The following function \(g\) models the rate, \(R\text{,}\) at which the rain falls (in cm/hr) on the time interval \(t=0\) to \(t=10\text{:}\)
    \begin{equation*} R = g(t) = \frac{4}{t+2} +1. \end{equation*}
    🔗

    (a)

    Compute \(g(3)\) and write a complete sentence to explain its meaning in the given context, including units.
    🔗
    🔗

    (b)

    Compute the average rate of change of \(g\) on the time interval \([3,5]\) and write two careful complete sentences to explain the meaning of this value in the context of the problem, including units. Explicitly address what the value you compute tells you about how rain is falling over a certain time interval, and what you should expect as time goes on.
    🔗
    🔗

    (c)

    Plot the function \(y=g(t)\) using a computational device (desmos?). On the domain \([0,10]\text{,}\) what is the corresponding range of \(g\text{?}\) Why does the function \(g\) have an inverse function?
    🔗
    🔗

    (d)

    Determine \(g^{-1}(\frac95)\) and write a complete sentence to explain its meaning in the given context.
    🔗
    🔗

    (e)

    According to the model \(g\text{,}\) is there ever a time during the storm that the rain falls at a rate of exactly \(1\) centimeter per hour? Why or why not? Provide an algebraic justification for your answer.
