    Quadratic Functions.

    🔗
    A quadratic function is one that may be written in the form
    \begin{equation*} q(x)=ax^2 + bx + c \end{equation*}
    where \(a \ne 0\text{.}\) That is, there is an \(x^2\) term but no higher powers of \(x\text{.}\)
    🔗

    Activity 32. Activity 1.5.2.

    Open a browser and go to Desmos, desmos.com. In a cell in Desmos, enter \(q(x) = ax^2 + bx + c\) in exactly that form; you will be prompted to add sliders for \(a, b,\) and \(c\text{.}\) Do so. Then begin exploring with the sliders and respond to the following questions.
    🔗

    (a)

    Describe how changing the value of \(a\) affects the graph of \(q\text{.}\)

    Quadratic Formula - Solutions to \(q(x)=0\).

    Let \(a\text{,}\) \(b\text{,}\) and \(c\) be real numbers with \(a\ne0\text{.}\) The equation \(ax^2+bx+c =0\) can have \(0, 1\text{,}\) or \(2\) real solutions. These real solutions are given by the quadratic formula,
    \begin{equation*} x = \frac{-b \pm \sqrt{b^2-4ac}}{2a} \end{equation*}
    provided \(b^2 - 4ac \ge 0\text{.}\)
    🔗
    🔗

    The vertex of a parabola.

    The quadratic function \(y=q(x) = ax^2+bx+c\) has its vertex at the \(x\)-coordinate \(\ds x = -\frac{b}{2a}\text{.}\)
    🔗
    When \(a>0\text{,}\) the graph opens upward, and thus the vertex is the lowest point on the graph of \(q\) (see example on the left below). When \(a<0\text{,}\) the graph opens downward, and so the vertex is the highest point (see example on the right below).
    🔗
    The graph is symmetric around the line \(\ds x = -\frac{b}{2a}\) (the vertical line that passes through the vertex!).
    🔗
    🔗

    Vertex form of a quadratic function.

    A quadratic function with vertex \((h,k)\) may be written in the form \(y = a(x-h)^2+k\text{.}\) The constant \(a\) may be determined from one other function value for an input \(x\ne h\text{.}\)
    🔗
    🔗

    Activity 34.

    🔗
    🔗
    🔗
    Just a note: objects that fall under the force of gravity, like baseballs or water balloons or anything, can be modeled by quadratic curves.

    Composite Functions.

    🔗

    Definition 35. Definition 1.6.2.

    If \(f\) and \(g\) are functions such that \({g:A\rightarrow B}\) and \({f:B\rightarrow C}\text{,}\) we define the composition of \(f\) and \(g\) to be the new function \({h:A\rightarrow C}\) given by
    \begin{equation*} h(t) = f(g(t)). \end{equation*}
    We also sometimes use the notation \({h = f\circ g}\) (said " \(f\) compose \(g\) " or " \(f\) of \(g\) "), where \({f\circ g}\) is the single function defined by
    \begin{equation*} (f\circ g)(t) = f(g(t))\text{.} \end{equation*}
    🔗
    🔗
    It’s a function within a function! Work inside out. Take the result of one function, and plug it right back into another function.
    🔗

    Example 36.

    Suppose \(f\) is a function with \(f(3)=4\) and \(g\) is a function with \(g(4)=5\text{.}\) Let’s find
    \begin{equation*} g(f(3)). \end{equation*}
    That is, we want to find "\(g\) or \(f\) of \(3\text{.}\)" Since we work from the inside out, we will plug \(3\) into \(f\) and then whatever that outputs we plug back into \(g\text{.}\) We know \(f(3)=4\text{,}\) so we can replace \(f(3)\) with \(4\text{.}\) Then we can simplify just that part first:
    \begin{equation*} g(f(3)) = g(4). \end{equation*}
    But now we are looking for \(g(4)\) which we know is 5. So thinking in stages we have
    \begin{equation*} g(f(3)) = g(4) = 5. \end{equation*}
    On the other hand, if we were to switch and have
    \begin{equation*} f(g(3)), \end{equation*}
    we would need to take \(g(3)\) first since it is on the inside. We don’t know what that is... So at the moment, we cannot simplify \(f(g(3))\) until we have more information.
    🔗
    🔗
